- 推进 Phase 3 的下一小步：QA 从规则拼接升级为“检索结果 + LLM 生成回答”

  - QA 先完成检索和 citations 选择，再将命中片段作为上下文交给 LLM 生成最终回答

- 推进 PostgreSQL / pgvector 落地准备：

  - PostgreSQL 启动时自动准备 `vector` 扩展与 `memory_chunks` 向量索引
  - 修正 pgvector ORM 查询表达式，改为显式 `cast(..., Vector(...))`
  - 新增 `backend/scripts/check_pgvector_ready.py` 用于检查扩展和索引准备情况
