# 2026-05-29 开发日志

## 今日完成

- 截图持久化与详情预览切片。
  - 后端新增 `/api/v1/ingest/image`，支持 PNG / JPEG / WebP / GIF / BMP 上传。
  - 后端挂载 `/uploads` 静态目录，新截图会保存到用户维度的上传目录，并写入记忆 `source_url` / `file_name` 元数据。
  - 首页超级输入区保存图片附件时改走图片上传接口，不再只保存“附件文件名”文本。
  - 首页记录卡片支持图片缩略图预览。
  - 详情页支持截图大图预览；旧截图记录如果没有原图资产，会显示“旧记录未保存原图”的明确提示。
- 前端时间展示统一为北京时间。
  - `formatDateTime` / `formatDateTimeLong` / `formatDateLabel` 固定使用 `Asia/Shanghai`。
  - 对后端返回的无时区时间按 UTC 解析后再展示为北京时间，避免文档/附件记录显示成 UTC 小时。
- 指定记录问答防跑偏切片。
  - QA 请求新增 `context_memory_id`，用户从某条记录唤起 AI 时，后端直接以该记忆为唯一上下文回答。
  - 显式上下文问答跳过全局 insight / fact 路由，避免“问文档却回答消费趋势”。
  - 若记录只有附件文件名、没有正文，AI 会明确提示无法总结原文，不再用其他记忆凑答案。
  - 新上传 Markdown / TXT / CSV / JSON / YAML / LOG 等文本文件时，前端会读取文件正文并保存进记忆，后续可直接总结。
- 记录删除切片。
  - 后端新增 `DELETE /api/v1/memories/{memory_id}`，对记录执行软删除。
  - 删除记录时会归档由该记录自动生成的待办和提醒，并失效洞察缓存。
  - 首页记录卡片增加删除图标，详情页增加“删除记录”按钮，删除前使用确认弹窗防误触。
- 首页提醒自定义时间切片。
  - 记录卡片提醒弹层保留快捷选项，并新增 `datetime-local` 自定义时间输入。
  - 自定义时间保存后复用现有待办 `due_at` / 提醒同步链路，后台通知调度无需新增接口。
  - 打开已有待办提醒时，会自动回填当前提醒时间。
