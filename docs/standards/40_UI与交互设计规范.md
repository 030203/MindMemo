# UI 与交互设计规范

## 产品界面定位

这是一个高频使用的工作台，不是营销页。

## 布局规则

统一采用：

1. 左侧导航
2. 中间主工作区
3. 右侧辅助信息或详情区

## 页面设计要求

1. Dashboard 首屏必须同时展示：
   - 快速记录入口
   - 今日重点
   - 最近记忆
   - AI 摘要
2. Memory 页面优先信息清晰，而不是视觉花哨。
3. Chat 页面必须保留引用来源区域。
4. Review Queue 页面必须突出“AI 建议”和“用户确认”。

## 交互规则

1. 所有高风险动作必须二次确认或显式授权。
2. AI 生成内容必须有状态提示：
   - 解析中
   - 已完成
   - 需确认
3. 列表页与详情页之间要有明确回跳路径。

## 风格规则

1. 工具型、克制、可长时间使用。
2. 信息密度适中，优先可读性。
3. 不做卡片套卡片的装饰性结构。
4. 用一致的状态色表示：
   - success
   - warning
   - danger
   - info

## 当前 UI 开发重点

1. 保持现有工作台布局稳定。
2. 先补功能状态，不急着做视觉重构。
3. 等真实数据链路稳定后，再做交互细化。
