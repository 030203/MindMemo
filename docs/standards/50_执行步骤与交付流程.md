# 执行步骤与交付流程

## 每日开始前

1. 查看 `PROJECT_WORK_GUIDE.md`
2. 查看 `docs/standards/10_分阶段开发路线图.md`
3. 查看最近一条 `dev_logs/YYYY-MM-DD.md`
4. 只选择一个明确切片作为当天主任务

## 单个开发切片标准流程

### Step 1：锁定范围

回答 3 个问题：

1. 这一步只改什么
2. 这一步不改什么
3. 完成标志是什么

### Step 2：实现

1. 优先改最小文件集
2. 先保证接口和数据结构稳定
3. 不做无关重构

### Step 3：验证

至少做一项：

- `npm run build`
- 后端 import check
- API smoke test
- 页面访问验证

### Step 4：记录

更新当天日志，写清：

- 完成事项
- 验证结果
- 剩余待办

## Definition of Done

一个切片要视为完成，至少需要：

1. 代码或文档已落盘
2. 基础验证已通过
3. 若变更契约，相关文档已同步
4. 当天日志已更新

## 禁止事项

1. 一次同时推进多个大模块
2. 在未验证前继续叠加后续开发
3. 不记录完成项和待办项
