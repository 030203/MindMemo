# 开发需求基线

## MVP 必须实现

1. Memo 记录
2. TODO 管理
3. Timeline
4. Memory Detail
5. AI 自动分类 / 标签 / 摘要
6. 基于长期记忆的 QA
7. Review Queue
8. 主动提醒基础能力

## MVP 应优先支持的输入

1. 文本输入
2. TODO 输入
3. URL 导入
4. 文本型 PDF

## MVP 不作为当前强制项

1. 浏览器插件
2. 扫描件 OCR
3. 真正图记忆 / Neo4j
4. 多模态图片理解
5. 复杂自治 Agent
6. 本地与云的双向实时同步

## 开发边界

### 可以延后但要留接口

- 多模型切换
- 周报增强
- 风险分析增强
- 更复杂的用户偏好记忆

### 当前不允许做成黑盒的能力

1. 自动修改核心用户数据
2. 未授权自动创建任务
3. 无来源的 AI 回答

## 功能优先级

| 优先级 | 内容 |
|---|---|
| P0 | 数据层、QA、Timeline、基础提醒 |
| P1 | PDF/URL 摄取、Review Queue、用户系统 |
| P2 | 每日总结、风险提醒、提醒通道增强 |
| P3 | 图记忆、插件、移动端、同步 |
