## 文档分工

| 文件 | 用途 |
|---|---|
| `MySecondBrain_需求分析_V1.1.md` | 全量产品、架构和执行基线 |
| `10_分阶段开发路线图.md` | 控制开发节奏，避免一次做太多 |
| `11_AI_Agent长期演进路线图.md` | MVP 后 Phase 7-16 的 AI Agent / RAG / 长期记忆路线 |
| `20_开发需求基线.md` | 锁定 MVP 范围和暂不开发范围 |
| `30_技术实现规范.md` | 统一后端、前端、数据和 API 规则 |
| `40_UI与交互设计规范.md` | 统一页面结构、信息密度和交互风格 |
| `50_执行步骤与交付流程.md` | 每次开发任务的执行闭环 |
| `60_测试与验收规范.md` | 保证每一步可验证 |
| `70_开发日志规范.md` | 保证每天有记录、有待办 |

## 使用方式

1. 开工前先看路线图和当前日志。
2. 开发时只选择一个小切片推进。
3. 完成后按测试规范验证。
4. 最后更新当天日志。
