# 测试与验收规范

## 最低验证要求

### 前端

- 构建通过
- 核心页面可访问
- 核心接口数据能展示

### 后端

- 应用可启动
- `/health` 可访问
- 关键 API 返回正确结构

## 阶段性验收要求

### 数据层阶段

- 真实数据库读写正常
- 列表页与详情页数据一致
- Timeline 能反映新增/完成动作

### 检索阶段

- 至少支持一个真实问答场景
- citations 返回非空
- 检索不足时不乱答

### 提醒阶段

- 至少一条提醒通道打通
- 有频控规则
- reminder 状态可追踪

## 回归检查清单

每次较大改动后至少检查：

1. Dashboard
2. Inbox
3. Memories
4. Todo Center
5. Timeline
6. AI Chat

## 演示验收

面试或演示时至少可走通：

1. 创建一条记忆
2. 创建一条 TODO
3. 查看 Timeline
4. 提问并看到来源引用
5. 展示待确认项或提醒
